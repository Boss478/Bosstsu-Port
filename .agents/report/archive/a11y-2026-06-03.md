### Violation Details

#### 1. `color-contrast` — [serious] — 43 occurrences across 8 pages

**WCAG:** 1.4.3 Contrast (Minimum)

| Page | Foreground | Background | Ratio | Target | Issue |
|------|-----------|------------|-------|--------|-------|
| All pages | `#52525c` | `#0f172b` | **2.3:1** | Footer spans (`.dark\:text-zinc-600`) | Needs 4.5:1 |
| All listing pages | `#71717b` | `#0f172b` | **3.69:1** | `.dark\:text-zinc-500` | Needs 4.5:1 |
| Homepage hero | `#242838` | `#020618` | **1.37:1** | `.md\:text-2xl` subtitle | Needs 4.5:1 |
| Homepage hero | `#1c1f30` | `#020618` | **1.23:1** | `.text-zinc-500.text-lg` span | Needs 4.5:1 |
| All listing pages | `#ffffff` | `#2b7fff` | **3.76:1** | Blue CTA buttons (`.bg-blue-500`) | Needs 4.5:1 |
| Listing filter bar | `#71717b` | `#020618` | **4.17:1** | `.mt-2` result count | Needs 4.5:1 |
| Games cards | `#9f9fa9` | `#505868` | **2.72:1** | Game descriptions (dark mode) | Needs 4.5:1 |
| Games cards | `#71717b` | `#505868` | **1.48:1** | Category badges (dark mode) | Needs 4.5:1 |
| Number Game | `#ed6aff` | `#ababac` | **1.12:1** | `h1` heading (fuchsia on gray) | Needs 3:1 (large text) |
| Number Game | `#9f9fa9` | `#ababac` | **1.14:1** | Subtitle / paragraph | Needs 4.5:1 |

**Fix priority:** HIGH — most widespread, affects dark mode readability significantly.

#### 2. `select-name` — [critical] — 4 occurrences

**WCAG:** 4.1.2 Name, Role, Value

**Pages:** Portfolio, Gallery, Resources, Games

The `<select>` elements used for filtering/sorting have no associated `<label>`, `aria-label`, or `aria-labelledby`.

**Fix priority:** HIGH — critical impact, screen readers cannot identify filter controls.

#### 3. `link-name` — [serious] — 6 occurrences

**WCAG:** 2.4.4 Link Purpose (In Context)

**Pages:** Portfolio, Gallery (list + detail), Resources, Games

The breadcrumb home link (`<a href="/">`) contains only an `<i class="fi fi-sr-home">` icon with no accessible text. Screen readers read the icon's CSS content (Flaticon codepoint) or skip it entirely.

**Fix priority:** HIGH — breadcrumb navigation is a key landmark.

#### 4. `heading-order` — [moderate] — 7 occurrences

**WCAG:** 1.3.1 Info and Relationships

**Pages:** All except homepage and python-compiler (7/8)

Headings skip from `h1` → `h3` without an `h2` level. Common pattern: page title is `h1`, category/album/game cards use `h3` for sub-headings but there's no `h2` wrapper.

**Fix priority:** MEDIUM — assistive technology can still navigate but hierarchy is confusing.

#### 5. `page-has-heading-one` — [moderate] — 1 occurrence

**WCAG:** 1.3.1 Info and Relationships

**Page:** Python Compiler (`/resources/python-compiler`)

The loading state renders a spinner with no `h1` heading. The `h1` is only added after client-side hydration completes.

**Fix priority:** MEDIUM — affects users who encounter the loading state (likely transient).

## Fix Recommendations (Prioritized)

### High Priority
1. **Add `aria-label` to filter/sort `<select>` elements** — affects 4 pages, critical severity
2. **Add accessible name to breadcrumb home icon link** — affects 6 pages, serious severity
3. **Fix dark mode footer text contrast** (`#52525c` → `#a1a1aa` or lighter on `#0f172b` — currently 2.3:1)
4. **Fix homepage hero dark mode text** (`#242838` on `#020618` currently 1.37:1 — needs 4.5:1)

### Medium Priority
5. **Fix heading hierarchy** — wrap card sections in `<h2>` tags
6. **Fix blue CTA button contrast** — darken `#2b7fff` to `#1a6aff` or use white text on darker blue
7. **Fix Number Game h1 contrast** — dark mode fuchsia `#ed6aff` on gray `#ababac` = 1.12:1
8. **Add `aria-hidden="true"` to Flaticon `<i>` icons** — prevent screen reader noise

### Low Priority
9. **Add `aria-label="Main navigation"` to `<nav>`**
10. **Python Compiler loading state** — include `<h1>` in initial HTML
