## The "vocab-generators flake" → real bug, fixed
- Reproduced with assertion: `generateCollocationQuestions` — `expected 3 to be 4`.
- Root cause: filler loop `options.push(wordPool[random].word)` sampled **with replacement**; dedup (`new Set`) only after → duplicate filler collapsed options below 4. P(⅓)/question with the test's 3-word pool → ~50% per run.
- Fixed the **same bug class at 6 sites** (collocations, synonyms, antonyms, fill-blank, minimal-pairs word-to-ipa + ipa-to-word): sample fillers **without replacement** from unique pool values not already used; converges, no infinite loop.
- Regression pin: 300-iteration test on the exact flake data (collapses with near-certainty under the bug; never with the fix). Verified: vocab file **45/45 × 5 runs**, sibling suites 38/38, **full suite 1107 tests green (873 unit + 234 db)**.
- Follow-up (NOT fixed): 4 `while…if (!includes) push(ipa)` loops (~1235/1265/1595/1701) — latent hang risk if the guard never fires; unproven, ticketed in flake ticket.
