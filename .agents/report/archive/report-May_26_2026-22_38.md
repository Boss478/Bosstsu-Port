### Features
1. **yahoo-finance2** — real stock quotes + historical data from Yahoo Finance; circuit breaker (10 consecutive failures stops auto-refresh); progressive backoff (3+ failures doubles interval); in-memory history cache (5min for 1d/5d, 1h for others)
2. **Editable Portfolio** — inline editing for shares, avgCost, and manualPrice per holding; manual price overrides market price with blue-dot visual indicator
3. **StockDetailModal** — company header with logo, large price/change, period selector (10 periods), PriceChart embed, 12-field stats grid
4. **Row click → chart** — clicking a portfolio row opens StockDetailModal
5. **Refresh + interval** — manual refresh button (↻), auto-refresh dropdown (Off, 1min, 5min, 15min, 30min)
6. **Hourly 1D** — `generateMockHistory` produces 39 hourly data points for 1D view; `HH:MM` chart labels
7. **Overview aggregation** — Portfolio Summary (total value/P&L/best/worst) + Following Summary (count/best/worst)
8. **English localization** — all dashboard UI text converted from Thai to English
9. **Single PERIOD_CONFIG** — 10 periods (1D/5D/1W/1M/3M/6M/YTD/1Y/5Y/Max) exported as single source of truth

### Scrutiny Fixes Applied
- Race guard: singleton `refreshPromise` prevents concurrent fetches
- Circuit breaker: 10 consecutive Yahoo failures stops auto-refresh
- Progressive backoff: 3+ failures doubles effective interval (cap 30min)
- Null safety: all Yahoo API fields have `??` fallbacks
- Period selector: horizontal scroll on mobile (no wrapping)
- Fallback: smooth random walk regenerates both prices AND chart history
- History cache: `(symbol + period)` key, per-period TTLs

## Key Technical Decisions

| Decision | Rationale |
|----------|-----------|
| `yahoo-finance2` chosen over Alpha Vantage/Finnhub | No API key needed, richest data, unlimited (unofficial) calls |
| Circuit breaker at 10 failures | Prevents IP-block from aggressive polling |
| Cache TTL at 5min for short periods | Balances freshness with rate-limit safety |
| `any` casts with eslint-disable in API route | Yahoo API return types are complex and partially typed; `any` is practical for the data-mapping pattern |
| Mock data as initial state | UI renders immediately; real data loads asynchronously behind it |
