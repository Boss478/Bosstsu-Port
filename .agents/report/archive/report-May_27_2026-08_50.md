# Report: Stock Dashboard Production Hardening

**Version:** v1.9.20 | **Date:** 2026-05-27 | **Component:** Private Stock Dashboard

## Summary

Production-hardened the private stock dashboard: added 20 Thai SET stocks + live market indices (S&P 500, NASDAQ, DJIA, SET, SET50), persisted watchlist to MongoDB, added per-tab error boundaries, sortable table, shared enrichment hook, market state indicator (Thai/US), currency-per-row display, and loading skeletons. ## Bugs Found & Fixed (via Scrutiny)

### Bug 1: filterMarketHours hardcoded to US market hours

**Symptom:** Thai 1D charts would show "No chart data" — data points silently filtered out.

**Root cause:** `filterMarketHours()` at `StockDataContext.tsx:273` only checked `13:30-20:00 UTC` (US session). Thai stock timestamps (03:00-09:30 UTC) were all excluded.

**Fix:** Added `isThai` parameter — Thai session filter `03:00-09:30 UTC` when `symbol.endsWith('.BK')`. Call site updated to pass `stock.symbol.endsWith('.BK')`.

### Bug 2: Market state useMemo([], []) never updates

**Symptom:** Market open/closed banner frozen at page-load time.

**Root cause:** `useMemo(() => computeMarketState(new Date()), [])` with empty deps only evaluates once.

**Fix:** Added `marketClock` state with 60s `setInterval`. `useMemo` depends on `marketClock`. This is required for correctness, not an optimization.

### Bug 3: Skeleton check misses first render frame

**Symptom:** Brief flash of empty/no-data state before skeleton appears.

**Root cause:** Check `stocks.length === 0 && isLoading` — on first render, `isLoading` is still `false` (initial state), so the condition is `true && false`.

**Fix:** Nested check: `if (stocks.length === 0) { if (isLoading) show skeleton; else show "no data" }`.

### Bug 4: Quotes fetch only covers DEFAULT_SYMBOLS

**Symptom:** US stocks in watchlist would have $0 price, 0% change — no data ever loaded.

**Root cause:** `doActualRefresh()` posted `symbols: DEFAULT_SYMBOLS`. If that only contained Thai stocks, US symbols like 'AAPL' were never fetched.

**Fix:** Combined 27-symbol set: `DEFAULT_SYMBOLS = [...THAI_20, ...US_7]`.

### Bug 5: 27 individual Yahoo HTTP requests

**Symptom:** 27 parallel connections to Yahoo may hit rate limits or OS connection pool limits.

**Root cause:** `symbols.map(s => yahooFinance.quote(s))` with `Promise.allSettled`.

**Fix:** Single `yahooFinance.quote(symbols)` call with array input — Yahoo's batch endpoint.

## Key Decisions

| Decision                    | Rationale                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------- |
| 27 combined symbols         | Quotes fetch is hardcoded to DEFAULT_SYMBOLS — must cover both sets                                |
| Single batch Yahoo call     | Reduces HTTP from 27 to 1; Yahoo batch handles per-symbol errors internally                       |
| Symbol-aware filter         | Thai 03:00-09:30 UTC vs US 13:30-20:00 UTC — silently dropping one market's data is unacceptable  |
| CPN-only MOCK_PORTFOLIO     | Placeholder holdings require user cleanup on first login — bad UX                                   |
| Per-row currency            | Thai stocks in THB, US stocks in USD — suffix check `.endsWith('.BK')` is simple and reliable      |
| Interval required for marketClock | `useMemo([], [])` freezes at mount — 60s interval is correctness, not optimization           |
