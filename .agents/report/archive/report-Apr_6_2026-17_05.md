# Report — Phase 2: Server-Side Pagination, Filtering & Sort

**Version:** 1.5.2 → 1.5.3

### `src/app/(website)/portfolio/data.ts`
* No structural changes (type preserved)

* Same pattern as portfolio — URL params, skip/limit, projection
* Queries: `find`, `countDocuments`, `distinct('tags')`

* Same rewrite as PortfolioClient — removed `useMemo`/local state, URL-driven nav
