## Impact Analysis

- **Positive**: Every size/type/quality/pagination setting is now in one file. To change pagination across the whole public site, edit 3 numbers in config.ts instead of 3 files. To adjust upload quality, edit one section.
- **Risk**: None — same default values. Type-safe via `as const`.
