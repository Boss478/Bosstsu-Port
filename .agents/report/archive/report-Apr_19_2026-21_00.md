### `src/components/admin/RichTextEditor.tsx` (full rewrite)

**Before:** Single toolbar row with only Bold, Italic, Underline, Strikethrough, and 8-color text color picker.

**After:** Two-row toolbar with:

| Row | Controls |
|-----|---------|
| 1 | Block Format (P/H1–H6 dropdown), Font Size (10–48px dropdown), B/I/U/S, Text Color (16 colors), Alignment (L/C/R/J) |
| 2 | Bullet List, Ordered List, Indent, Outdent, Link (inline dialog), Unlink, Image URL (inline dialog), Horizontal Rule, Remove Formatting |

**Key implementation details:**
- `OpenPanel` discriminated union (`'none' | 'blockFormat' | 'fontSize' | 'color' | 'link' | 'image'`) — only one panel open at a time
- `FormatState` interface tracks 10 active format states, updated on `onKeyUp`/`onMouseUp`
- Font size: `execCommand('fontSize', '7')` → immediately convert `<font size="7">` to `<span style="font-size: Npx">` for clean HTML output
- Link/Image: save selection on dialog open, restore on apply — no native `prompt()` used
- All toolbar buttons use `onMouseDown + e.preventDefault()` to prevent editor losing focus
- `ToolbarDivider` defined outside the component (avoids re-mount on each render)
- `suppressContentEditableWarning` added to contentEditable div

**Props unchanged:** `name`, `defaultValue`, `placeholder`, `required` — fully backward compatible with existing `LearningForm.tsx`.
