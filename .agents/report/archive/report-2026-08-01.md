### Key Decisions
- **`React.memo` dropped**: ineffective without data restructuring (new object identity each render). Grouped return objects + targeted re-render control instead.
- **Achievement checking centralized** in one function called from 2 places (per scrutiny) — no scattered award logic.
- **Practice sessions bypass map-save entirely** to keep review replayable without polluting progress.
- **44px impossible for 9 keys on 375px**: used 36px min-width + flex-wrap fallback (WCAG-adjacent ≥32px secondary targets).
