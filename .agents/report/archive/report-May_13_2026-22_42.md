# Post-Task Report — One-page HTML Game Support

**Date:** 2026-05-13 22:42 (local) / 15:42 UTC
**Version:** v1.5.23
**Task:** Add one-page HTML game support to admin and public games pages

---

## What Changed

### 1. `src/models/Game.ts`
- Added `htmlContent?: string` to `IGame` interface
- Added `htmlContent: { type: String }` to Mongoose schema (optional)

### 2. `src/components/admin/GameForm.tsx`
- Added `gameType` state (`'url' | 'html'`), initialized from `initialData?.htmlContent`
- Added radio button group: "External Site (URL)" / "One-page HTML"
- Conditional field rendering:
  - URL mode: shows `playUrl` text input (required)
  - HTML mode: shows `htmlContent` textarea (required, monospace, 10 rows) + hidden empty `playUrl`
- Added helper text under HTML textarea in Thai

### 3. `src/app/admin/games/actions.ts`
- Imported `DOMPurify` from `isomorphic-dompurify`
- Extended `gameSchema`:
  - Added `gameType: z.enum(['url', 'html'])`
  - Made `playUrl` and `htmlContent` optional at object level
  - Added `.refine()` validations:
    - URL mode: `playUrl` must be valid URL or relative path
    - HTML mode: `htmlContent` must be non-empty
- `createGame` and `updateGame`:
  - Parse `gameType` from formData
  - Sanitize `htmlContent` with `DOMPurify.sanitize()` before storing
  - Store `playUrl: ''` for HTML games (satisfies model requirement)
  - Store `htmlContent: undefined` when not provided (clears on mode switch)

### 4. `src/app/(website)/games/data.ts`
- Added `isHtmlContent: boolean` to `GameItem` interface

### 5. `src/app/(website)/games/page.tsx`
- Map logic updated:
  - `hasHtml = !!doc.htmlContent`
  - `link` set to `/games/play/${id}` for HTML games, `playUrl` for URL games
  - `isHtmlContent: hasHtml` passed to client

### 6. `src/app/(website)/games/GamesClient.tsx`
- `<a>` tag `target` and `rel` are now conditional:
  - HTML games: `target=undefined`, `rel=undefined` (same-tab navigation)
  - URL games: `target="_blank"`, `rel="noopener noreferrer"` (new tab)

### 7. NEW: `src/app/(website)/games/play/[id]/page.tsx`
- Server component:
  - Validates `ObjectId` with `mongoose.isValidObjectId()`
  - Fetches game by `_id` using `findById().lean()`
  - Redirects to `/games` if game missing or has no `htmlContent`
  - Passes sanitized data to `PlayView` client component

### 8. NEW: `src/app/(website)/games/play/[id]/PlayView.tsx`
- Client component:
  - Dark immersive layout (`bg-slate-950`)
  - Header bar with:
    - Back link to `/games` (Flaticon `fi fi-sr-angle-left`)
    - Game title (centered, truncated)
    - Full-screen button (`fi fi-sr-expand`) calling `requestFullscreen()` on iframe container
  - Full-height iframe with `srcDoc={htmlContent}` and `sandbox="allow-scripts"`
