- Poll GET strips `studentToken`/`editToken`/`ip`; server computes `isOwn` per doc (QuickQuiz preserved).

- QA vote: rate-limited (responseId:ip:token), response-exists + active-session + `qa_board`-type checks.

- SSE idle-close now decrements `totalClients` (400-cap leak fixed).
- `removeClient` gated on `sessionClients.delete()` result (double-decrement bug found by new unit test).

## 3. Notable gotchas (persisted to memory)
1. **Review agents read stale state** — all 3 claimed QABoard `qc` was undefined; it was already fixed on disk. Verify against source + typecheck before trusting.
2. **Same-file parallel edits silently drop** (4 occurrences). One edit per file per message; verify with `git diff`.
3. **Failed pre-commit leaves autofix artifacts** — lint-staged's `eslint --fix`/prettier wrote 9 unrelated files (added unused type imports → tsc breakage) and its revert doesn't undo them. Check `git status` after any failed commit.
4. **Pre-existing lint debt** in `use-sse.ts` (react-compiler: render-phase ref mutation, circular useCallback TDZ, sync setState in effect) blocked the commit — fixed via ref-pattern + `queueMicrotask`. This is why `ignoreBuildErrors` existed; the gate is now genuinely green.
5. **Aggregate `$match` doesn't auto-cast ObjectId** — find() casts strings, aggregate() doesn't.
