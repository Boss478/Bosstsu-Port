## Key Design Decisions

1. **Shared utility extracted** — PortfolioForm's inline `uploadFileWithProgress` moved to `client-upload.ts` to serve all forms, preventing 3x code duplication
2. **All server actions accept URLs** — Consistent architecture: files uploaded client-side, server actions only receive URLs. Matches the existing portfolio pattern
3. **Client-side file type validation** — LearningForm validates MIME types before upload (mirrors server-side checks), giving instant feedback
4. **Gallery cover Blob→File** — Same `new File([blob], ...)` pattern as PortfolioForm for cropped ImageCropper output
5. **`games` folder added** — Was already in `FOLDERS_CONVERT_TO_WEBP` but missing from `ALLOWED_FOLDERS`, would block uploads server-side
6. **SaveProgress modal** — Consistent UX across all 4 forms: centered modal with spinner, animated progress bar, percentage, status text, green checkmark on completion
7. **Retry logic** — All file uploads use `uploadFileWithRetry` (3 attempts, 1s delay between retries)
8. **Toast only on completion** — Modal handles in-flight UX, toast only fires on final success/error (same as PortfolioForm)
