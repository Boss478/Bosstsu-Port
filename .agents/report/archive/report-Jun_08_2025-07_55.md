**Date:** 2026-06-08 07:55

## Changes

### CardFrame Glow
- `CardFrame.tsx` — Added tier-colored `box-shadow` glow via CSS custom properties (`--glow-rgb`). Two-layer shadow (inner + outer aura). `group-hover` fades to transparent. `showBack` suppresses glow. `pointer-events: none` on glow layer with `pointer-events: auto` on children.
- Uses CSS `rgba(var(--glow-rgb), opacity)` — `TIER_GLOW` stores RGB triple strings.

### Accessibility
- `MenuScreen.tsx` — Easy Mode toggle: `role="switch"`, `aria-pressed={easyMode}`, 🐣 emoji `aria-hidden`
- `CardRevealModal.tsx` — Card flip div: `tabIndex={0}`, `role="button"`, `onKeyDown` (Enter/Space), `aria-label`
- `GameOverlays.tsx` — Collection close button: `aria-label="Close collection"`. Streak 🔥 emoji: `aria-hidden`
- `CardScreen.tsx` — Back button `aria-label="Back to game"`. 👑 crown emoji, achievement icons, empty state emoji: all `aria-hidden`
