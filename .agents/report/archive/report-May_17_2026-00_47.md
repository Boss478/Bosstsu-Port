### Keys Learned
- Next.js 16 standalone `output` tries to prerender ALL server components at build time, even those with `searchParams`. Any page calling `dbConnect()` (directly or via helper functions like `getTagsByCategory`) must be marked `force-dynamic` to avoid build failures when MongoDB is unavailable.
- List pages with `revalidate = N` also get prerendered. Replace with `dynamic = 'force-dynamic'` when DB is needed.
- `generateStaticParams` connecting to MongoDB must use try-catch and return `[]` during build.
