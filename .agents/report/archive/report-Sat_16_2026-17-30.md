### Key Design Decisions
1. **Multi-stage Dockerfile** — Keeps final image small (~300MB), no dev dependencies at runtime
2. **Caddy over Nginx** — Automatic HTTPS ready when domain is available, simpler config
3. **Named volumes** — Persists MongoDB data and uploads across container rebuilds
4. **No bind mounts** — Code baked into image, no dependency on host filesystem
5. **Internal-only ports** — MongoDB, app, and mongo-express bound to 127.0.0.1 only
