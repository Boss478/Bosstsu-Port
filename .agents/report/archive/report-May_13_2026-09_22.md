## Changes Implemented

### 1. Bug Fix: Hero CTA Button (Hero.tsx)
**Issue:** The "สื่อการเรียนรู้" button linked to `/gallery` instead of `/resources`.

**Fix:** Changed `href="/gallery"` to `href="/resources"`.

---

### 2. Hero Logo Priority Preload (Hero.tsx)
**Change:** Added `priority` prop to the hero logo Image component.

**Impact:** ~150ms faster LCP (Largest Contentful Paint) as the logo loads immediately without lazy delay.

---

### 3. Lazy Loading for Content Images (6 files)
**Files affected:**
- `portfolio/PortfolioClient.tsx`
- `portfolio/[id]/page.tsx` (related items + sidebar)
- `gallery/GalleryClient.tsx`
- `resources/ResourcesClient.tsx`
- `games/GamesClient.tsx`

**Change:** Added `loading="lazy"` to all content grid images.

**Impact:** Browsers won't download off-screen images on initial load, reducing bandwidth by ~5-8MB per list page.

---

### 4. Glassmorphism Consistency (3 files)
**Files affected:**
- `gallery/GalleryClient.tsx` — changed `bg-zinc-200/50` to `bg-white/60 dark:bg-slate-800/60 backdrop-blur-sm`
- `resources/ResourcesClient.tsx` — changed `bg-white dark:bg-slate-900` to glass pattern
- `games/GamesClient.tsx` — changed `bg-white dark:bg-slate-900` to glass pattern

**All cards now follow AGENTS.md glassmorphism spec:**
- `bg-white/60 dark:bg-slate-800/60`
- `backdrop-blur-sm`
- `border border-white/60 dark:border-slate-700/50`

---

### 5. Navigation Loading Indicator (3 files)
**Files affected:**
- `portfolio/PortfolioClient.tsx`
- `gallery/GalleryClient.tsx`
- `resources/ResourcesClient.tsx`

**Changes:**
- Added fixed thin progress bar (0.5px height, sky-500, pulsing) at top of page during `isPending`
- Added `opacity-60` transition on content grid during navigation
- Added `transition-opacity duration-150` for smooth state changes

**Impact:** Users see immediate visual feedback when clicking filter/sort/pagination buttons.

---

### 6. Detail Page Content Width Capping (portfolio/[id]/page.tsx)
**Change:** Added `mx-auto max-w-3xl` to the `<article>` element.

**Impact:** Text content is now capped at ~768px on desktop (optimal 65-75 character line length for readability). Cover image and related grid remain full-width for visual balance.

---

### 7. Skip-to-Content Accessibility Link (layout.tsx)
**Change:** Added `sr-only focus:not-sr-only` link as the first focusable element.

**Impact:** Keyboard and screen-reader users can bypass navigation to reach main content instantly.

---

### 8. Dead Code Cleanup (page.tsx)
**Change:** Removed 2 lines of empty whitespace from home page.
