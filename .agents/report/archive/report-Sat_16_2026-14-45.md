# Report: Study Tool Live Results Fix

**Date/Time:** 2026-05-16 14:45

## Problem
- Live results in MentimeterPoll (polls) were showing incorrect/disappearing counts
- After submission, no warning if user tries to refresh browser

## Changes Made

### 1. Fixed Vanishing Results Bug (Root Cause)
**Files:** `MentimeterPoll.tsx`, `QABoard.tsx`, `DiscussionForum.tsx`
- Removed `since` parameter from all `fetch` calls and intervals
- Now polls fetch the full latest set (up to 50 results) every 10 seconds
- Removed `lastFetch` state from all three components

### 2. Manual Refresh Button
**Files:** All three polling components
- Added `refreshing` state + `handleRefresh` function
- Added refresh button (`fi-sr-refresh` with spin animation) to Live Results header
- MentimeterPoll also shows `totalCount` from API for accurate vote count

### 3. Browser Refresh Warning
**Files:** `MentimeterPoll.tsx`, `QuickQuiz.tsx`, `AssignmentForm.tsx`, `ExitTicketForm.tsx`
- Added `beforeunload` event listener that triggers after `submitted === true`
- Shows browser warning dialog when user tries to refresh/close tab after submission

## Version Bump
- `1.7.0` → `1.7.1`
- Changelog updated
