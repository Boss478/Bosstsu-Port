## Key Decisions

1. **`transform: translateX()` shimmer** — not `background-position`. The `translateX` approach is GPU-composited (handled on the compositor thread), so it produces zero CPU paint per frame. `background-position` triggers layout/paint on the CPU.

2. **Plain `.skeleton` CSS class** — TailwindCSS 4 `@utility` blocks cannot contain `::after` pseudo-element selectors. A regular CSS class is required.

3. **Co-located `loading.tsx`** — No shared component. Each file is self-contained and independently editable. Pure Server Components with no imports.

4. **Gotcha fix applied in resources** — `relative aspect-video overflow-hidden shrink-0 skeleton` on the image wrapper (no child needed), preventing the `aspect-video w-full` inside `flex flex-col` collapse to 0 height.
