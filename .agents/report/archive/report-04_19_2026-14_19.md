## Changes

### 1. Dependencies Added
- `react-quill@2.0.0` - HTML Editor for Article type
- `react-pdf@7.x` + `pdfjs-dist` - PDF viewing support
- Installed with `--legacy-peer-deps` (React 19 peer dependency conflict)

### 2. Learning Model (`src/models/Learning.ts`)
Added new fields:
- `content?: string` - HTML content for Article
- `embedCode?: string` - Embedded iframe for Scratch/Interactive
- `fileUrl?: string` - Uploaded file for Presentation/Lesson Plan/Sheet/Worksheet
- `youtubeId?: string` - YouTube video ID for Video type
- `canvaEmbed?: string` - Canva embed URL for Presentation

### 3. LearningForm Component (`src/components/admin/LearningForm.tsx`)
- Subject options now Thai (English): คณิตศาสตร์ (Mathematics), วิทยาศาสตร์ (Science), etc.
- Added 8 Type Options: Article, Presentation, Video, Lesson Plan, Sheet, Worksheet, Scratch, Interactive
- Type-specific UI rendering based on selected type
- React Quill integration for HTML editor (Article)
- File upload sections with type-specific accept attributes

### 4. Server Actions (`src/app/admin/resources/actions.ts`)
- Type-specific validation rules per resource type
- File type validation (PDF for Lesson Plan, JPG/PNG/PDF for Sheet/Worksheet)
- DOMPurify sanitization at write-time for HTML content
- Extended Zod schemas with type-specific fields

### 5. Config (`src/lib/config.ts`)
- Added 'learning' to ALLOWED_FOLDERS for file uploads
