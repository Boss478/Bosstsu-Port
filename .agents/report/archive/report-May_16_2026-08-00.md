## Technical Details

### Ownership Pattern
- Server generates `crypto.randomUUID()` on response creation
- Stored in `editToken` field + returned to client
- Client stores in `localStorage` with tool-specific key (e.g., `padlet_{sessionId}`)
- On edit request, client sends `responseId` + `editToken`
- Server verifies token matches before allowing edit

### Poll Anti-Refresh
- Uses soft approach (client-side only) per user requirement
- Reason: school networks share public IP, strict IP-based would block multiple students
- Stores `poll_voted_{sessionId}` in localStorage
- On mount: checks localStorage, immediately shows "already voted" if found
- User can clear localStorage to vote again (soft enforcement)

### Edit Support
- **Assignment**: After submit shows summary card + "Edit My Answer" button → restores form with prefilled values
- **Padlet**: Each own post shows pencil icon → inline textarea with Save/Cancel
- **Discussion**: Each own reply shows pencil icon → inline textarea with Save/Cancel
- NOT included (per user): Q&A Board, Exit Ticket, Poll, Quiz
