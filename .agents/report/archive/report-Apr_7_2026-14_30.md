## Phase 1 Fixes (from plan)

### Fix 1: Admin Pagination Loses Search/Sort Params — APPLIED

**Files**: `src/app/admin/portfolio/page.tsx`, `src/app/admin/gallery/page.tsx`

- Both files had `buildPaginationQuery()` helper functions (lines 44-49 each)

## Additional Fixes (Pre-existing Build Blockers)

### Fix 4: Game Model Field Mismatch (genre → category)

**Files**: `src/app/admin/games/actions.ts`, `src/app/admin/games/page.tsx`

- Zod schema used `genre` but Game model has `category`
- Build was failing with: "genre does not exist in type..."

- Cast to `as string[]` on both constants
- Pre-existing build blocker, unrelated to Phase 1 but needed to verify the build
