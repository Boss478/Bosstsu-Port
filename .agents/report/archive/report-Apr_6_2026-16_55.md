## Changes Summary

### P0 — Critical Bugs Fixed
1. **Number Game endless mode progression** — `startEndless()` no longer resets `stage: 1`, causing wrong stage progression or immediate victory when entering endless after completing normal game.
2. **Number Game stale closures** — `gameState` captured in `setTimeout` was stale by callback time. Added `stateRef` pattern (`useRef` + sync) so timeout reads latest value.
3. **SpellChecker stale word history** — `pickNextWord()` called inside `setWordStats` callback read stale `recentWordHistory` from closure. Added `recentWordHistoryRef` pattern.
4. **MongoDB index bypass** — `{ published: { $ne: false } }` prevented compound index usage. Changed to `{ published: true }` for optimal index scan.

### P1 — Performance
5. **useCallback dependency bloat** — Alphabet's `loadRound` depended on `[gameState, roundData]`, Number's `generateQuestion` on `[range, gameState]`. Both recreated on every render. Narrowed to `[]` with explicit param passing.
6. **ISR revalidation** — Games page `revalidate` from 60s → 300s (content rarely changes).
7. **SpellChecker timer polling** — Interval from 100ms → 1000ms (only displays whole seconds).

### P2 — UI/UX & Consistency
8. **NO GRADIENTS violation** — GamesClient used `bg-linear-to-t` on overlay and `bg-linear-to-br from-sky-400 to-indigo-500` on placeholder. Replaced with solid `bg-black/60` and `bg-sky-500`.
9. **GameItem type duplication** — Client component redefined interface locally instead of importing from `data.ts`. Now uses centralized `import type { GameItem } from "./data"`.
10. **Search scope** — Games search now includes description and tags, not just title.
11. **Invalid z-index** — SpellChecker `z-100` → `z-50` (100 is not a valid Tailwind z-index).
12. **Victory screen navigation** — Added "Back to Games" button on both Alphabet Adventure and Number Game victory screens.
13. **Typing focus indicator** — Alphabet level 4 typing inputs had `focus:outline-hidden` hiding cursor focus. Replaced with `focus:outline-2 focus:outline-violet-500 rounded`.
