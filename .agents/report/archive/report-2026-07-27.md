## What Went Wrong

1. **T1 factual error** — Claimed "0 test files" when 41 existed in `tests/`. Root cause: `find` command was scoped to `src/` only. Fix: ran `find tests` and corrected registry.
2. **C3 over-classification** — Originally labeled Impact 3 "data integrity." Actual issue was cosmetic naming inconsistency (`type` vs `name`). Fixed in scrutiny.
3. **`home` screen type error** — Original WordBuilderScreen used `setScreen('home')` which was never a valid `Screen` type. Error was masked by `typescript.ignoreBuildErrors: true`.
4. **Broadcast test expecting 400 ** — Without auth, endpoint returns 401 before field validation. Test assumed 400 would take priority. Corrected to only test 401.

---

## Learning Points

- **Always scope `find` to ALL dirs, not just `src/`** when counting test files
- **Trace the call graph before asserting** — the broadcast auth check happens before field validation, so 401 takes priority over 400
- **Extract shared types early** — when splitting components, shared types/interfaces/constants should go to a shared module first
- **E2E tests with cold starts need longer timeouts** — VPS is single-core, first request is slow (MongoDB connection)
