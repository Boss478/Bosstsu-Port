# Task Report: Python Compiler Improvements

**Date:** May 14, 2026 11:54

## Summary
Fixed 3 critical bugs + 6 improvements in the Python Compiler.

### Critical Bugs Fixed

1. **Pyodide Worker Recreation on Mode Switch**
   - Root cause: `appendOutput` had `[mode]` dependency, causing effect re-run on every mode change
   - Fix: Added `modeRef`, made `appendOutput` stable with empty deps
   - File: `PythonCompilerClient.tsx`

2. **Error Messages Swallowed**
   - Root cause: `.split("\\n")` splits on literal `\n` (2 chars), not actual newlines
   - Fix: Changed to `.split("\n")` in pyodide-worker.js
   - File: `public/pyodide-worker.js:102,104`

3. **Output Truncation Silently Drops Content**
   - Fix: Added truncation notice + keeps recent content

### Other Improvements

- Added type assertion for `document.execCommand` (ts(6387) fix)
- Added async error handling to `submitConsoleInput`
- Added `modeRef.current` usage in `handleEditorClick`
- Replaced `alert()` with styled toast notification
- Added focus to editor after RUN completes
- Added `title="Run (Ctrl+Enter)"` to RUN button
