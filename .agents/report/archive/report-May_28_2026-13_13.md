# Feature Report: Budget Planner + Quick-Add Bar

**Version:** v1.9.23 | **Date:** 2026-05-28 13:13 | **Type:** Feature Addition

---

## Summary

Added two features to the Finance Tracker: (1) Budget Planner tab with per-month category budget limits, editable fields, save, and copy-from-last-month; (2) Quick-Add inline bar for rapid single-line transaction entry with local-state prepend (no full re-fetch), client-side validation, and category switching by type toggle.

## Scrutiny Findings Applied

| # | Finding | Action |
|---|---------|--------|
| 1 | (MAJOR) Quick-Add triggers full re-fetch on every save | QuickAddBar accepts `onAdd` callback; TransactionList passes `(tx) => setTransactions(prev => [tx, ...prev])` — no re-fetch |
| 2 | (MINOR) Missing client-side validation for empty amount/category | QuickAddBar validates `amount > 0` and `category !== ''` before POST |
| 3 | (MINOR) Category dropdown must switch with type | QuickAddBar computes `categories = type === 'income' ? INCOME_CATS : EXPENSE_CATS` reactively; resets category on type change |
| 4 | (NIT) BudgetUtils.ts over-engineered for one function | Budget utility function (`previousMonth`) inlined directly in `BudgetList.tsx` — no separate file |

---

## Architecture Decisions

- **Budget API uses upsert**: `findOneAndUpdate` with `upsert: true` on POST — clean create-or-update semantics
- **QuickAddBar shown only on current month**: Conditionally rendered when `month === today's YYYY-MM` — prevents adding to past months by accident
- **Local-state prepend over re-fetch**: `onAdd` callback prepends the API response to the local `transactions` array — saves 1 HTTP round trip per entry
- **No new dependencies**: Uses existing Flaticon icons (`fi-sr-budget`, `fi-sr-copy`, `fi-sr-floppy-disk`) — all verified against CSS
