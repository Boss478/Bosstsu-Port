# Rule: I18n

Source: @ AGENTS.md Code Style & UI + Known Gotchas

## I18n (TH/EN)

- Bilingual TH/EN — one language per commit subject (commit-msg hook enforces).
- Fonts: Mali + Geist Sans/Mono via `next/font/local`.
- Thai descenders ภ ว ม ห ฤ ร at 2xl+: avoid `bg-clip-text`, `leading-tight`; use `leading-relaxed`.
- Copywriter + locale-reviewer for bilingual content.
- Match surrounding style; no unsolicited refactoring outside scope.
- Keep concise — one language per subject, greppable history.

## Thai Rendering

- 2xl+ descender bleed → `leading-relaxed` required; `text-sm` carries its own line-height in Tailwind 4.
